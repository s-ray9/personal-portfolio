## Development

### Local Setup

```bash
# Clone the repository
git clone https://github.com/s-ray9/personal-portfolio.git
cd personal-portfolio

# Install dependencies
pnpm install
```

### Usage

```bash
# Run development server
pnpm dev

# Compile production build
pnpm build

# Preview production build
pnpm preview
```

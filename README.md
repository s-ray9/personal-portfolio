## Getting started

### Prerequisites

- Git
- Node.js (v26.x)
- pnpm (v12.16.1+)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/s-ray9/personal-portfolio.git
   cd personal-portfolio
   ```

2. Install dependencies:

   ```bash
   pnpm install
   ```

### Development

Start the local development server:

```bash
pnpm dev
```

Format the code:

```bash
pnpm format
```

### Build

Build the project:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```
